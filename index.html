✨ Core Features

Designed for executor scenarios, balancing flexibility and ease of use.

Multi-SDK Integration

Native support for Junkie, Panda Auth, Luarmor, and custom HTTP backends.

Persistent Storage

Keys are saved locally and auto-validated on subsequent launches.

Keyless Mode

Skip the key system entirely with configurable keyless mode options.

Modern UI Design

Adapts to Roblox executor visual style with smooth animations.

Custom Validation

Define your own key validation logic with full control.

Auto Update Check

Built-in update mechanism to stay compatible with latest SDKs.

📋 Usage

Integrate in three steps, quick start.

1
Download Files
Get PatriotUi.luau and Example.lua from GitHub.
2
Choose SDK
Specify Junkie, Panda, Luarmor or CustomHttp during init.
3
Initialize & Use
Call PatriotUi:setSdk() with your credentials and start verification.

-- Patriot Key System · Junkie SDK Init
local PatriotUi = require(script.Parent.PatriotUi)

PatriotUi:setSdk("Junkie", {
    apiKey = "your_junkie_api_key",
    secretKey = "your_junkie_secret",
    timeout = 30
})
-- Patriot Key System · Panda Auth Init
local PatriotUi = require(script.Parent.PatriotUi)

PatriotUi:setSdk("Panda", {
    publicKey = "your_panda_public_key",
    privateKey = "your_panda_private_key",
    sandbox = true
})
-- Patriot Key System · Luarmor API Init
local PatriotUi = require(script.Parent.PatriotUi)

PatriotUi:setSdk("Luarmor", {
    apiKey = "your_luarmor_api_key",
    productId = "your_product_id",
    encryption = true
})
-- Patriot Key System · Custom HTTP Init
local PatriotUi = require(script.Parent.PatriotUi)

PatriotUi:setSdk("CustomHttp", {
    baseUrl = "https://your-api.com/v1",
    headers = {
        ["Content-Type"] = "application/json",
        ["X-API-Key"] = "your_api_key"
    },
    auth = {
        type = "Bearer",
        token = "your_bearer_token"
    },
    endpoints = {
        verify = "/keys/verify"
    },
    timeout = 20
})
